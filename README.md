# Похоронная книга Жижеля

Интерактивная книга-реестр для кампании D&D.

## Возможности

- Добавление, редактирование и удаление записей о людях.
- Имя, возраст, статус (жив / мёртв / нежить), оплата, родственники и заметки.
- До пяти основных записей на одной странице; при добавлении шестой книга перелистывается автоматически.
- Рукописная роспись чёрным пером на странице.
- Настройка толщины пера, выбор и перемещение отдельного штриха, удаление выбранного штриха или всех рисунков страницы.
- Учёт доходов и выплат помощнику в отдельном журнале.
- Подробная монетная ведомость раскрывается по кнопке; краткая статистика людей и заработка всегда видна.
- Подсчёт клиентов вместе с указанными родственниками.
- Автоматический пересчёт остатков по курсу D&D: 10 медных = 1 серебряная, 2 электрумовые = 1 золотая, 10 золотых = 1 платиновая.
- Экспорт и импорт резервной копии JSON.

## Публикация

Сайт размещён на GitHub Pages: https://mrgreen10g.github.io/zhizhel-funeral-ledger/

GitHub Actions автоматически публикует `index.html` и иконку приложения при каждом push в ветку `main`.

## Хранение данных

Записи, выплаты и росписи сохраняются в `localStorage` браузера на текущем устройстве. Данные не загружаются в GitHub и не синхронизируются между устройствами.

Для переноса книги используй меню **Резервная копия → Экспорт JSON** и **Импорт JSON**. Экспорт включает записи, родственников, выплаты и рисунки.
