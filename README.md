# Архив Жижеля Плачеля

Личное приложение для кампании D&D «Проклятие Страда». Без сюжетных спойлеров.

## Разделы
- Похоронная книга: записи, родня, статусы, доходы, журнал выплат, страницы по пять записей, росписи пером.
- Архив компромата: досье привязаны к идентификаторам людей из книги; тайны, слабости, долги, достоверность, источники.
- Паутина знакомств: интерактивное дерево, родня из книги, ручные связи, перетаскивание, масштаб, переходы в досье.
- Проект «Бессмертие»: гипотезы, сделки, вопросы, источники, цена и дальнейшие шаги.
- Книга надгробных речей: 72 оригинальных текста в девяти стилях, поиск, случайный выбор, персонализация и личные версии.
- Письма Мире: личный дневник.
- Доска расследований: перемещаемые карточки, красные нити, подписи, ссылки на записи архива.
- Журнал заданий: состояние, важность, заказчик, награда, следующий шаг.
- Хроника приключения: события, сессии, место и последствия.

## Данные и резервные копии
Все пользовательские данные остаются в localStorage на текущем устройстве. Они не отправляются в GitHub, не синхронизируются и не шифруются. Названия разделов и заготовки речей являются частью публичного кода сайта.

Меню «Резервная копия» экспортирует весь архив в один JSON: исходную книгу, расходы, рисунки, досье, граф связей, доску и остальные записи. Старые файлы книги совместимы; при импорте старого формата новые разделы сохраняются, а ссылки на удалённые записи могут стать недоступны. Перед импортом или очисткой данных браузера сохраните резервную копию.

В дереве одноимённые родственники без однозначного совпадения с основной записью представлены отдельными узлами. Дополнительные отношения добавляются вручную.

Речи — авторские заготовки; персонализация выполняется на устройстве, без внешней ИИ-модели. Для подгрузки веб-шрифтов может требоваться интернет.
