# Похоронная книга Жижеля

Однофайловое приложение для ведения реестра персонажей и клиентов Жижеля в D&D.

## Возможности

- Добавление, редактирование и удаление записей.
- Имя, возраст, статус (жив / мёртв / нежить), оплата и заметки.
- Неограниченное число родственников в одной записи.
- Валюта оплаты: бронза, серебро или золото.
- Перелистывание страниц с автоматическим созданием новых.
- Рукописное оформление записей и состаренная бумага.
- Локальное сохранение в браузере.
- Экспорт и импорт резервной копии JSON.

## Публикация

Сайт размещён на GitHub Pages: https://mrgreen10g.github.io/zhizhel-funeral-ledger/

GitHub Actions автоматически публикует `index.html` при каждом push в ветку `main`. Workflow находится в `.github/workflows/pages.yml`.

## Данные и резервное копирование

Записи сохраняются в `localStorage` браузера на текущем устройстве. Они не загружаются в GitHub и не синхронизируются между игроками или устройствами.

Для переноса данных используй кнопки **Экспорт** и **Импорт** в верхней части книги. Экспорт создаёт JSON-файл с резервной копией.
