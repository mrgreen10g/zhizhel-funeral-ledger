# Похоронная книга Жижеля

Атмосферная интерактивная книга-реестр для персонажа D&D.

## Возможности

- Добавление, редактирование и удаление записей.
- Имя, возраст, статус (жив / мёртв / нежить), оплата и заметки.
- Неограниченное число родственников в одной записи.
- Валюта оплаты: бронза, серебро или золото.
- Перелистывание страниц с автоматическим созданием новых.
- Локальное сохранение в браузере.
- Экспорт и импорт резервной копии JSON.

## Публикация

Сайт публикуется через GitHub Actions и GitHub Pages. Workflow находится в `.github/workflows/pages.yml` и автоматически:

1. Распаковывает `site-source.tar.gz.b64`.
2. Собирает статические файлы в каталог `dist`.
3. Публикует каталог на GitHub Pages.

После первого push открой **Settings → Pages** и проверь, что в **Build and deployment → Source** выбрано **GitHub Actions**. Workflow также пытается включить Pages автоматически.

## Данные

Записи сохраняются в `localStorage` браузера на текущем устройстве. Они не загружаются в GitHub и не синхронизируются между игроками. Для переноса книги используй кнопки экспорта и импорта JSON.

Исходники сайта хранятся в архиве `site-source.tar.gz.b64`. Для локального извлечения:

```sh
base64 -d site-source.tar.gz.b64 | tar -xz
```
